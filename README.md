# Convergence Analysis and Recent Improvements of the AAA Algorithm

This repository contains the LaTeX source for a paper on the AAA algorithm.

## Files

- `AAA.tex` – main LaTeX document
- `AAA.bib` – BibTeX references
- `Convergence_Analysis_and_Recent_Improvements_of_the_AAA_Algorithm.pdf` – PDF document
- `.github/workflows/compile.yml` – GitHub Actions workflow to compile the PDF
- `.github/workflows/spellcheck.yml` – GitHub Actions workflow to run spell check

  
## How to get the PDF

Every push to the `main` branch triggers automatic compilation. The resulting PDF is available as an artifact in the "Actions" tab.
